# Catatan mentoring

Master memilih /teach untuk memahami rumus dan alur program, bukan hanya menyalin kode. Mulai dari latihan hitungan; jangan menyatakan penguasaan hanya karena materi telah disampaikan.

Urutan: EAR, MAR, threshold/durasi/reset, tiga status, eksperimen adaptif, regresi logistik, evaluasi.
